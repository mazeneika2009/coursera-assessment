# Paradise Nursery Shopping Application

## Project Overview
**Paradise Nursery** is a front-end e-commerce web application built with React and Redux Toolkit. Users can browse a curated collection of indoor houseplants organized by category, add plants to their shopping cart, adjust item quantities, and view real-time cart totals.

## Features
- **Landing Page:** Welcomes visitors with company details and a "Get Started" button to enter the shop.
- **Product Listing Page:** Displays plants grouped into categories (Air Purifying Plants, Aromatic Fragrant Plants, and Medicinal Plants) with dynamic "Add to Cart" buttons that disable once added.
- **Shopping Cart Page:** Allows users to increment, decrement, or remove items while automatically calculating individual subtotals and the total cart cost.
- **Redux State Management:** Uses `@reduxjs/toolkit` to manage global cart state across components.

## Technologies Used
- React 18
- Redux Toolkit & React-Redux
- Vite
- CSS3
